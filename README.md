# A/B Тест Алгоритма Рекомендаций

## 📌 Описание проекта

В этом проекте проводится **A/B-тестирование алгоритмов рекомендаций** в ленте мессенджера. Пользователи были случайным образом разделены на две группы:

- **Группа A** — пользователи, получающие рекомендации по **старому алгоритму**;
- **Группа B** — пользователи, получающие рекомендации по **новому алгоритму**.

🔍 Цель исследования — определить, какой из алгоритмов работает эффективнее, и принять решение о внедрении нового подхода для всех пользователей приложения.

Основной метрикой для сравнения выступает **CTR (Click-Through Rate)** — показатель вовлечённости пользователей в ленту рекомендаций.

---

## 📊 Проведённые шаги

- Загрузка и предобработка данных;
- Расчёт CTR для каждой группы;
- Проверка гипотез о значимости различий с использованием статистических методов;
- Визуальный анализ распределений и выводов;
- Формулировка итогов и бизнес-рекомендаций.

Все шаги и выводы подробно оформлены в Jupyter Notebook.

---

## 🛠️ Используемые библиотеки и технологии

- **Обработка данных**: `pandas`, `pandahouse`
- **Визуализация**: `seaborn`, `matplotlib.pyplot`
- **Статистический анализ**:
  - t-тест (`scipy.stats.ttest_ind`)
  - тест Манна–Уитни (`scipy.stats.mannwhitneyu`)
  - непараметрический бутстрэп
  - банкетное преобразование
- **Графики распределений**:
  - `sns.boxplot`
  - `sns.violinplot`

## ✅ Выводы

Результаты анализа позволяют сделать вывод о том, насколько эффективно работает новый алгоритм рекомендаций по сравнению со старым. Были выявлены (или не выявлены) статистически значимые различия в показателях CTR, что позволило дать обоснованные рекомендации по внедрению нового алгоритма в продакшн.
